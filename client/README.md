# StackAI - Frontend

StackAI is an all-in-one AI-powered productivity platform that brings together content generation, image generation, background/object removal, resume review, resume builder, and a vibrant community to showcase AI creativity.  
This repository contains the **Frontend** built with **React.js** following a reusable, component-based architecture.

---

## ✨ Features
- 🌐 **AI Tools Dashboard** – Access multiple tools in one place (Articles, Blogs, Resume review, Resume builder, etc.)
- 🖼️ **AI Image Generation** – Generate, remove background, or remove objects using Clipdrop API
- 👥 **Community Section** – Explore publicly shared AI-generated images
- 🔐 **Authentication & Billing** – Integrated Clerk for secure login, signup, and subscription flow
- 🚀 **Reusable Components** – Designed with scalability and maintainability in mind
- 📱 **Responsive UI** – Built with React + TailwindCSS/Bootstrap for seamless experience across devices

---

## 🛠️ Tech Stack
- **React.js**
- **React Router DOM**
- **Clerk Authentication**
- **Tailwind CSS / Bootstrap**
- **Axios** (API calls)
- **Cloudinary** (for image rendering)
